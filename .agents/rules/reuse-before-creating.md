# Reuse Before Creating

Before creating or duplicating anything, search the existing codebase.

Ask:

* Does this already exist?
* Can it be reused?
* Can it be extended?
* Is there an existing component, hook, API function, service, DTO, type, or utility?

Prefer extending existing implementations over creating duplicates.

Do not create abstractions simply because two pieces of code look similar.

Prefer clear, simple code over unnecessary abstraction.
