# Responsive & Accessible UI

The application must work well across mobile, tablet, and desktop.

Follow the project's existing responsive breakpoints and patterns.

Do not introduce arbitrary breakpoints without a genuine requirement.

Build accessibility into every feature:

* Use semantic HTML.
* Provide accessible labels.
* Support keyboard interaction.
* Preserve visible focus states.
* Use accessible dialogs and forms.
* Communicate validation and errors clearly.

Prioritize mobile usability for attendance and outreach workflows because these features may be used directly at the dojo.
